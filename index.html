Interface Universal para Rádios

Diniz-RF
📊 TABELA DE PINAGEM (RJ45)

⚠️ ATENÇÃO: Referência do conector fêmea da interface.

Pino Função Aplicação
1Entrada RX (Base)Áudio do rádio móvel. Proteção DC inclusa.
2COR NegativoAtivação via GND (Padrão Motorola).
3Saída TX (Mic)Áudio para o rádio. Ajustar ganho no Zello.
4/6GNDTerra comum (Áudio/Dados).
5PTT RádioChaveamento para transmissão (GND).
7COR PositivoAtivação via Voltagem (Vertex/Yaesu).
8RX + COR (HT)Uso em rádios portáteis (Baofeng/etc).
🔧 MODOS DE INSTALAÇÃO

🔷 MODO RÁDIO BASE / MÓVEL

  • Áudio RX conectado ao Pino 1.
  • Capacitor interno de 10µF para proteção.
  • Squelch via pinos 2 ou 7.
  • Ideal para estações fixas e repetidoras.

🔷 MODO HT (PORTÁTIL)

  • Áudio e COR unificados no Pino 8.
  • Dispensa abertura do rádio para pegar COR.
  • Chaveamento automático por presença de áudio.
  • Compatível com Baofeng, Quansheng, etc.

⚠️ AJUSTES NO ZELLO (CRÍTICO)

PROIBIDO O USO DE VOX NO SOFTWARE.

  • PTT: Em Opções > Botão PTT, mapeie o PTT do rádio como "F7".
  • Alertas: Mantenha alertas de áudio em 100%.
  • Bips: Desative bips de erro e conexão.
  • Hardware: A interface controla o tempo de queda fisicamente.

SUPORTE TÉCNICO

🧠 CONSIDERAÇÕES: Use cabos blindados nos pinos de áudio para evitar travamento de PTT por indução de RF. A interface possui isolamento galvânico parcial para sua segurança.
